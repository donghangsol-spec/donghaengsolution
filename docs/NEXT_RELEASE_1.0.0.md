# 동행솔루션 NEXT 1.0.0

출시 범위: 장기요양기관/세무업무용 직원·급여·4대보험 업무준비, 검증, 승인, 처리현황 관리.

## 출시 포함
- 멀티 사업장 선택 및 직원 마스터
- 월급제/시간제 급여대장 자동초안
- XLS/XLSX/CSV/JSON 급여자료 가져오기 및 오류 추적
- 지급총액/공제총액/실지급액 계산
- 급여대장 검증 → 승인권자 확정 → 확정 후 잠금
- 4대보험 취득/상실/변경 요청
- 국민연금/건강보험/고용보험/산재보험 보험별 상세 신고행
- 보험별 적용일/보수월액/근로시간/계약종료/직종/국적/체류정보 관리
- 자격 보조판정 및 확인필요 항목 담당자 검토확인
- 승인 전 최신 데이터 재검증 및 승인 우회 차단
- 사업장 교차연결 차단, 직원번호 중복 방지, 감사로그
- 2026 규칙/요율 버전 메타데이터 및 예상 4대보험 공제 계산
- 원자적 최초 사용자 온보딩

## 의도적으로 비활성화된 기능
NEXT 1.0.0에서는 아래 기능을 시판 기능으로 광고하거나 활성화하지 않는다.
- 공단/EDI 실제 자동 제출
- CAPTCHA/MFA/보안모듈 우회 자동화
- 공동인증서 원본/비밀번호 저장
- 브라우저에서 주민등록번호/외국인등록번호 원문 저장
- 건강보험/고용보험/산재보험의 불완전한 예외조건 자동 확정
- 원천세 간이세액표에 의한 완전 자동 원천세 확정
- 사업종류별 산재보험 사용자 요율 자동 확정

이 항목들은 공식 연계/규칙 검증과 별도 보안 경계가 완성된 이후 후속 버전에서 활성화한다.

## 출시 원칙
자동화 결과는 초안/보조판정이며, 신고 및 급여 확정 전 담당자 검토를 거친다. 4대보험 신고 보수월액과 실제 급여 기본급은 분리한다. 민감 인증정보는 애플리케이션 DB 및 브라우저에 저장하지 않는다.
