# 상담 메일 보존·삭제 결정 기록

상태: **제안 / 미승인 / 온라인 접수 OFF** (2026-09-28 KST). `CONTACT_INTAKE_ENABLED`를 설정하기 위한 운영 결정서이며 공개 개인정보 처리방침이 아니다. 기존 상담 메일을 이 문서만으로 삭제하거나 접수를 재개하지 않는다.

## 현재 확인한 사실

- 공개 `/contact`에는 전화 안내가 보이고 폼이 숨겨져 있다. 서버는 플래그가 없으면 POST를 거부한다. 2026-09-28에 브라우저로 공개 화면을 확인했으나 API 주소 직접 열기는 브라우저에서 차단되어 실제 POST 응답을 재검증하지 못했다. 회귀 테스트와 Vercel 배포 상태는 통과했다.
- 앱 DB에는 상담 본문을 저장하지 않는다. Resend 발송 메일과 수신 메일함, 전달·다운로드 사본이 처리 위치다.
- Resend 발송 목록의 **상담 제목 3건**을 메타데이터만으로 확인했다(2026-09-23 12:29, 2026-09-27 15:04·15:08 KST, 모두 delivered). 본문·수신자·전화번호는 이 기록에 복사하지 않았다. 수신 메일함에 남아 있는지, 실제 응대가 종료되었는지는 확인하지 않았다.
- Resend 문서는 일반 요금제의 이메일 데이터 보관 기간을 30일로 안내한다. 이는 **동행솔루션 수신 메일함/전달 사본의 삭제를 대신하지 않는다**. 메시지 내용 저장 비활성화는 유료 부가 기능 조건이 있으므로 현재 무결제 계획에 포함하지 않는다.

## 책임자가 승인할 제안

| 결정 항목 | 제안 | 승인 전 확인 |
| --- | --- | --- |
| 목적·항목 | 상담 회신에 필요한 성명·기관명, 연락처, 분야, 문의 내용만 | 수강 신청 등 자유 입력에 불필요한 개인정보를 넣지 않도록 안내 |
| 보존기간 | 최종 응대일로부터 30일, 응대가 없거나 종료일을 기록하지 못한 경우 접수일로부터 최대 90일 | 계약 체결·법정 분쟁 보존으로 넘어가는 자료는 별도 근거·기간·접근권한 기록; 목적 달성 시 더 이른 파기 여부 검토 |
| 처리 위치 | Resend 발송 기록, 수신 메일함, 전달·다운로드 사본 | 실제 수신 계정 및 담당자·공유 설정 확인; 수탁·국외 처리 고지 검토 |
| 삭제 실행 | 매월 첫 영업일에 종료·만료 상담을 찾아 메일함과 휴지통, 전달본/기기 사본 삭제; Resend 보관 만료 확인 | 메일함 검색 방법, 휴지통 영구삭제 권한, 백업 만료, 삭제 요청 시 제공자 처리 가능 범위 확인 |
| 요청·예외 | 정보주체 요청은 접수·본인 확인·근거 판정·처리·통지 시각 기록 | Resend의 30일 만료 전 개별 삭제 수단이 없을 경우 제공자 절차를 확인하고 불가하면 온라인 접수 재개 금지 |
| 책임자 | 상담함 담당자 1명과 대체자, 개인정보 책임 검토자 1명 지정 | 이름 대신 역할·연락 경로를 운영 기록에 지정; 접근권한 최소화 |

이 기간은 내부 **제안**이다. 개인정보 보호법은 목적 달성 또는 보유기간 경과로 불필요해진 개인정보의 지체 없는 파기를 요구한다. 따라서 위 상한일까지 무조건 보유한다는 뜻이 아니다. 책임자는 기간과 예외의 근거를 검토한 뒤 웹 고지·동의 문구, 실제 메일함 설정과 일치시켜 승인한다.

## 기존 3건 정리 절차

1. 담당자가 수신 메일함에서 해당 접수 건을 찾아 대응 상태·종료일·계약 전환/법정 보존 근거를 확인한다. 이 문서와 이슈 댓글에는 원문·수신자·연락처를 게시하지 않는다.
2. 각 건에 `접수일 / 종료일 / 보존 만료일 / 예외 근거 / 메일함·전달본·기기 사본 위치 / 삭제 여부 / 검토자`를 기록한다. 기록에는 개인 식별 내용을 최소화하고 접근을 제한한다.
3. 만료된 건만 승인된 절차로 삭제하고 메일함 휴지통과 공유·전달 사본을 확인한다. Resend 기록은 제공자 보관 만료/개별 삭제 가능 여부를 확인한다. 기존 건을 확인하기 전 일괄 삭제하지 않는다.

## 접수 재개 기준

- [ ] 보존기간·예외, 책임자, 공개 처리방침·동의 문구 승인
- [ ] 수신 메일함·전달 사본 위치와 삭제 권한 확인, 기존 3건 분류
- [ ] 삭제 요청 시 Resend 30일 내 처리 가능 범위 및 수탁/국외 처리 검토
- [ ] 실제 메일함의 합성 상담 1건으로 접수→종료→삭제·휴지통 제거 시험 (실제 고객 정보 사용 금지)
- [ ] 공개 페이지/서버 GET·POST 차단 및 승인 후 활성화 회귀 확인

완료 증적을 Issue #2에 남긴 뒤 Preview와 Production의 `CONTACT_INTAKE_ENABLED`를 각각 검토한다. 이 플래그는 다른 고객 데이터·기관 신고 게이트를 열지 않는다.
