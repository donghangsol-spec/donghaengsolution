# 동행솔루션 세무 AX Public Alpha

장기요양기관 중심의 회계·세무 AX 웹앱 공개 알파입니다.

## 현재 동작
- 사업장 설정
- 거래 CSV 업로드
- 적요 + 입출금 방향 기반 규칙 추천
- 검토필요 / AI초안 / 보완요청 / 승인완료 상태관리
- 미분류 거래 승인 차단
- 담당자 분류수정
- 승인 거래 기반 신고준비 상태
- 감사로그
- 브라우저 로컬 저장(localStorage)
- 모바일 반응형 UI

## 중요한 제한
현재 버전은 프런트엔드 공개 알파입니다. 로그인, 서버 DB, 실제 은행 연동, 홈택스·지방소득세·4대보험·희망이음 실제 전송은 구현하지 않았습니다.

공동인증서 원본이나 비밀번호를 수집·저장하지 않습니다. 실제 고객 데이터 운영 전에는 사용자 인증, 조직/권한, 서버 DB, 암호화, 서버 감사로그, 백업, 개인정보 처리체계가 필요합니다.

## 배포
main 브랜치 변경 시 GitHub Pages 워크플로가 자동으로 배포합니다.
